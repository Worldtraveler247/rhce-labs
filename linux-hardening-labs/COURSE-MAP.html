01
User and Password Security
Audit user accounts, enforce strong password policies with PAM and pwquality, set password aging, configure account lockout with faillock, and lock down sudo access.
pwquality.conf chage faillock visudo sudoers.d passwd -l login.defs
Beginner
02
SSH Hardening
The most attacked service on any server. Enforce key-only authentication, harden sshd_config (no root, custom port, allowlists), add a login banner, and block brute force with fail2ban.
ssh-keygen -t ed25519 PermitRootLogin no PasswordAuthentication no AllowUsers fail2ban sshd -t
Beginner
03
Firewall with firewalld
Control all inbound traffic with firewalld zones. Allow only what's needed. Use rich rules for per-IP filtering and rate limiting. Build a complete hardened server firewall profile.
zones firewall-cmd --permanent rich rules rate limiting --reload --panic-on
Beginner
— Intermediate —
04
SELinux
The most powerful security layer on RHEL — and the most misunderstood. Enforce MAC policies that confine even root. Manage file contexts, booleans, and port labels. Troubleshoot denials with audit2why.
getenforce / setenforce ls -Z chcon / restorecon semanage fcontext setsebool -P audit2why audit2allow
Intermediate
05
File Permissions and ACLs
Find and eliminate dangerous permissions. Audit SUID/SGID binaries. Use ACLs for fine-grained per-user access control. Make critical files immutable with chattr. Set secure umask.
find -perm -4000 SUID / SGID sticky bit getfacl / setfacl chattr +i umask 027
Intermediate
06
Audit Logging with auditd
Log everything at the kernel level — file access, privilege escalation, login events, system calls. Write audit rules, search logs with ausearch, generate reports with aureport.
auditctl -w -p wa / -p x -k keyword ausearch -k aureport -au augenrules --load
Intermediate
07
System Services and Attack Surface
Audit every running service and open port. Disable what isn't needed. Remove insecure legacy packages (telnet, ftp). Blacklist unnecessary kernel modules. Harden cron access and systemd unit files.
ss -tlnup systemctl disable dnf remove modprobe blacklist cron.allow systemd-analyze security
Intermediate
— Advanced —
08
Kernel Hardening with sysctl
Harden the Linux kernel itself. Enable ASLR, SYN cookie protection, anti-spoofing, disable IP forwarding, restrict /proc access, and block kernel pointer leaks. Based on CIS + STIG recommendations.
sysctl -w randomize_va_space=2 tcp_syncookies=1 kptr_restrict=2 hidepid=2 /etc/sysctl.d/
Advanced
09
Intrusion Detection with AIDE
Create a cryptographic filesystem baseline. Detect unauthorized changes to binaries, configs, and libraries. Automate daily checks. Know immediately if an attacker modifies a system file.
aide --init aide --check aide --update aide.conf sha512 checksums systemd timer
Advanced
10
Automate Hardening with Ansible
Turn everything in this series into a single Ansible role. One command hardens any server identically. Modular task files per category, validated templates, tags for selective application.
hardening role validate: sshd -t import_tasks --tags ssh --check --diff firewalld module
Advanced
