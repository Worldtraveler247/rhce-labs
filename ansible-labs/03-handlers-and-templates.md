# 03 - Handlers and Jinja2 Templates

**Series:** RHCE Ansible Labs  
**Lab:** 03 | **Prereq:** 02-conditionals-and-loops.md  
**Goal:** Trigger actions only when something changes (handlers), and generate dynamic config files (templates).

---

## 🧠 Concepts

### Handlers
A handler is a task that only runs when explicitly **notified** by another task — and only if that task made a change. Classic use case: restart a service only when its config file changed.

```yaml
tasks:
  - name: Copy nginx config
    copy:
      src: nginx.conf
      dest: /etc/nginx/nginx.conf
    notify: restart nginx    # ← triggers the handler IF this task changed

handlers:
  - name: restart nginx
    service:
      name: nginx
      state: restarted
```

If the config file was already correct (no change), the handler never runs. Efficient.

### Jinja2 Templates
Templates are files with `{{ variables }}` inside them. Ansible fills them in at runtime and copies the result to the target host. End with `.j2` extension.

## 🔬 Lab 1 — Handlers

```bash
mkdir -p ~/ansible-practice/03
nano ~/ansible-practice/03/handlers.yml
```

```yaml
---
- name: Handlers Lab
  hosts: localhost
  connection: local

  vars:
    config_content: "# Config version 1\napp_port=8080\n"

  tasks:
    - name: Write application config
      copy:
        content: "{{ config_content }}"
        dest: /tmp/myapp.conf
      notify:
        - reload app
        - log change

    - name: This task does NOT notify
      debug:
        msg: "Just printing, no change"

  handlers:
    - name: reload app
      debug:
        msg: "Handler fired: App would be reloaded now"

    - name: log change
      debug:
        msg: "Handler fired: Change logged"
```

```bash
ansible-playbook ~/ansible-practice/03/handlers.yml
```

Run it twice. First run: handlers fire. Second run: file unchanged, handlers are **skipped**.

## 🔬 Lab 2 — Force Handler Order with `flush_handlers`

Handlers run at the end of a play by default. Use `meta: flush_handlers` to run them immediately:

```yaml
---
- name: Flush Handlers Lab
  hosts: localhost
  connection: local

  tasks:
    - name: Update config
      copy:
        content: "updated=true\n"
        dest: /tmp/test.conf
      notify: restart service

    - name: Flush handlers NOW (before continuing)
      meta: flush_handlers

    - name: This runs AFTER the handler
      debug:
        msg: "Handler already ran above"

  handlers:
    - name: restart service
      debug:
        msg: "Service restarted!"
```

## 🔬 Lab 3 — Jinja2 Templates

### Create a template file

```bash
mkdir -p ~/ansible-practice/templates
nano ~/ansible-practice/templates/app.conf.j2
```

```jinja2
# Application Configuration
# Generated by Ansible on {{ ansible_date_time.date }}
# Host: {{ ansible_hostname }}

[application]
name        = {{ app_name }}
environment = {{ environment }}
port        = {{ app_port }}
debug       = {{ debug_mode | lower }}

[database]
host        = {{ db_host }}
port        = {{ db_port }}
name        = {{ db_name }}

[logging]
level       = {% if environment == 'prod' %}error{% elif environment == 'staging' %}warning{% else %}debug{% endif %}
```

### Create the playbook

```bash
nano ~/ansible-practice/03/templates.yml
```

```yaml
---
- name: Templates Lab
  hosts: localhost
  connection: local

  vars:
    app_name: "mywebapp"
    environment: "dev"
    app_port: 8080
    debug_mode: True
    db_host: "localhost"
    db_port: 5432
    db_name: "appdb"

  tasks:
    - name: Generate app config from template
      template:
        src: ../templates/app.conf.j2
        dest: /tmp/app.conf
        mode: '0644'

    - name: Show generated config
      command: cat /tmp/app.conf
      register: config_output

    - name: Display config
      debug:
        var: config_output.stdout_lines
```

```bash
ansible-playbook ~/ansible-practice/03/templates.yml
cat /tmp/app.conf
```

## 🔬 Lab 4 — Jinja2 Filters

Filters transform data inside templates:

```jinja2
# In templates or playbooks:

{{ "hello world" | upper }}           → HELLO WORLD
{{ "  trim me  " | trim }}            → trim me
{{ some_list | join(", ") }}          → item1, item2, item3
{{ some_list | length }}              → 3
{{ some_list | first }}               → first item
{{ some_list | last }}                → last item
{{ my_var | default("fallback") }}    → value or "fallback" if undefined
{{ port_number | string }}            → converts int to string
{{ "yes" | bool }}                    → True
{{ my_dict | to_nice_json }}          → pretty JSON
{{ my_dict | to_nice_yaml }}          → pretty YAML
```

### Test filters in a playbook

```bash
nano ~/ansible-practice/03/filters.yml
```

```yaml
---
- name: Jinja2 Filters Lab
  hosts: localhost
  connection: local

  vars:
    username: "  Ed Camacho  "
    packages: ["git", "curl", "vim", "htop"]
    undefined_var: ~   # null/undefined

  tasks:
    - name: String filters
      debug:
        msg:
          - "Upper: {{ username | trim | upper }}"
          - "Length: {{ username | trim | length }}"

    - name: List filters
      debug:
        msg:
          - "Joined: {{ packages | join(', ') }}"
          - "Count: {{ packages | length }}"
          - "First: {{ packages | first }}"
          - "Sorted: {{ packages | sort | join(', ') }}"

    - name: Default filter
      debug:
        msg: "Value: {{ undefined_var | default('not set') }}"
```

## 🔬 Lab 5 — Template with Loop

```bash
nano ~/ansible-practice/templates/vhosts.conf.j2
```

```jinja2
# Apache Virtual Hosts
# Generated: {{ ansible_date_time.iso8601 }}

{% for site in virtual_hosts %}
<VirtualHost *:80>
    ServerName {{ site.name }}
    DocumentRoot {{ site.docroot }}
    ErrorLog /var/log/apache2/{{ site.name }}-error.log
    {% if site.redirect_https is defined and site.redirect_https %}
    Redirect permanent / https://{{ site.name }}/
    {% endif %}
</VirtualHost>

{% endfor %}
```

```yaml
---
- name: Vhost Template Lab
  hosts: localhost
  connection: local

  vars:
    virtual_hosts:
      - name: "app.example.com"
        docroot: "/var/www/app"
        redirect_https: true
      - name: "static.example.com"
        docroot: "/var/www/static"
      - name: "api.example.com"
        docroot: "/var/www/api"
        redirect_https: true

  tasks:
    - name: Generate vhosts config
      template:
        src: ../templates/vhosts.conf.j2
        dest: /tmp/vhosts.conf

    - name: Show result
      command: cat /tmp/vhosts.conf
      register: out

    - debug:
        var: out.stdout_lines
```

## 📚 Key Takeaways

| Concept | What to Remember |
|---------|-----------------|
| `notify:` | Triggers a handler if the task changed |
| Handlers | Only run once, at end of play, only if notified |
| `meta: flush_handlers` | Run handlers immediately, mid-play |
| `.j2` extension | Convention for Jinja2 template files |
| `template:` module | Renders .j2 file and copies to host |
| `{{ var \| filter }}` | Apply transformations to variables |
| `{% if %}...{% endif %}` | Conditional blocks in templates |
| `{% for %}...{% endfor %}` | Loop blocks in templates |
