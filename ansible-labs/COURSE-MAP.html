00
Getting Started
Install Ansible, understand how it works, run your first ad-hoc commands against localhost. Learn the difference between ad-hoc commands and playbooks.
ansible --version ad-hoc commands -m ping inventory basics first playbook
Beginner
01
Variables and Facts
Store and reuse data with variables. Discover how Ansible automatically collects system info (facts) like hostname, OS, RAM, and IP. Capture task output with register.
vars: {{ variable }} gather_facts ansible_* register: vars_files: -e flag
Beginner
02
Conditionals and Loops
Control which tasks run using when: conditions. Repeat tasks over lists and dictionaries with loop:. Combine both for powerful filtering logic.
when: loop: item loop_control: is defined dict loops
Beginner
— Intermediate —
03
Handlers and Jinja2 Templates
Trigger service restarts only when config changes using handlers. Generate dynamic config files from templates using Jinja2 — variables, loops, and conditionals inside files.
notify: handlers: template: .j2 files Jinja2 filters {% if %} {% for %}
Intermediate
04
Roles — Organized, Reusable Playbooks
Stop writing monolithic playbooks. Structure tasks, handlers, templates, and variables into roles. Use ansible-galaxy to generate skeletons and install community roles.
ansible-galaxy role init tasks/main.yml defaults/main.yml handlers/main.yml meta/main.yml dependencies
Intermediate
05
Inventory and Groups
Manage multiple hosts and environments. Group servers logically (webservers, databases). Use group_vars and host_vars for clean variable organization. Introduction to dynamic inventory for cloud environments.
INI / YAML inventory group_vars/ host_vars/ group:children host patterns dynamic inventory
Intermediate
06
Ansible Vault — Encrypting Secrets
Encrypt passwords, API keys, and credentials using AES-256. Commit encrypted secrets safely to Git. Use vault password files for automation. Encrypt individual variables inline.
ansible-vault create ansible-vault encrypt ansible-vault edit sensitive: true vault IDs --ask-vault-pass
Intermediate
— Advanced —
07
Error Handling and Debugging
Handle failures gracefully instead of crashing. Use block/rescue/always (try/catch/finally). Define custom failure conditions. Debug with verbosity flags and step-through mode.
ignore_errors: failed_when: changed_when: block/rescue/always -v / -vvv --check --diff tags
Advanced
08
Advanced Playbooks
Production deployment patterns: rolling updates with serial, task delegation for load balancer coordination, async background tasks, retry loops, and modular playbook includes.
serial: delegate_to: run_once: async/poll until/retries include_tasks pre_tasks/post_tasks
Advanced
— Expert —
09
Full Project — Production Web Stack
Everything together: deploy a full LEMP stack (Linux, Nginx, MariaDB, PHP) using roles, vault, templates, handlers, rolling deployment, and post-task verification. The capstone project.
multi-role playbook vault secrets rolling serial: 1 pre/post tasks no_log: true --limit / --tags full stack deploy
Expert ✓
